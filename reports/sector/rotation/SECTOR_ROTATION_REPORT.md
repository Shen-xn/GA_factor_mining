# 板块轮动研究报告

**数据截止：2026-08-28｜分支：`main`｜特征协议：v4｜前向协议：v14｜执行策略：`simple_v2`**

## 结论

项目已经形成一个可重复运行的板块轮动参考闭环：季度扩展窗口LightGBM负责板块排序，市场状态与组合回撤控制绝对板块仓位，未配置资金进入货币ETF`511880.SH`。默认按单边20bp成本记账。

本轮正式晋级`simple_v2`。它不改模型、不加新因子，也不围绕2026行情改变市场状态规则，只做三项执行层调整：

1. 空位仍只从模型Top5买入；
2. 普通持仓至少持有10个交易日，跌出Top20才退出；
3. 组合回撤状态读取固定20bp政策参考净值，真实账户仍按实际交易成本完整记账。

固定政策参考净值的目的不是少扣费用，而是保证20bp、30bp和50bp压力测试仍然执行同一套投资决策。实际20bp与30bp完整回放中，1941个交易日的仓位与风险状态、3561条操作记录逐行一致。

`simple_v2`在2018-2025达到预先登记的收益、回撤、年度稳定性、持有期、换手和成本压力门，但仍不能称为已经验证的实盘产品：2024-2025参与过选择，2026已经被观察，真正属于v14的新样本还没有出现；权益ETF严格映射覆盖也仍不足，当前执行层明确为`blocked`。

## 当前规则

| 项目 | 当前口径 |
|---|---|
| 信号与执行 | `t`日收盘后形成计划，`t+1`日开盘成交 |
| 模型 | 18个人工特征，LightGBM季度扩展窗口重训 |
| 标签 | `open[t+6] / open[t+1] - 1`，标签必须在训练截止日前兑现 |
| 选板块 | 3日平滑评分，空位从Top5买入 |
| 普通退出 | 至少持有10日，跌出Top20退出 |
| 硬风险退出 | 持仓硬亏损、跟踪回撤或高波动弱动量可以提前退出 |
| 绝对仓位 | 市场状态给出0%、30%、70%或100%基础仓位，组合回撤上限可以继续压低 |
| 低风险腿 | 未配置资金进入`511880.SH`，不固定配置红利板块 |
| 默认成本 | 单边20bp |
| 风险参考成本 | 固定20bp；只驱动组合回撤状态，不替代真实成本记账 |
| 状态边界 | 从2018年连续承接，不在2024、2026或年度边界重置 |

## 成本压力与路径稳定性

| 单边成本 | 开发期累计 | 选择期累计 | 2018-2025累计 | 最大回撤 | 结论 |
|---:|---:|---:|---:|---:|---|
| 10bp | 33.99% | 45.14% | 94.47% | -15.77% | 通过 |
| 20bp | 23.31% | 40.49% | 73.24% | -16.75% | 默认路径，通过 |
| 30bp | 13.49% | 35.98% | 54.32% | -18.44% | 通过成本门 |
| 50bp | -3.89% | 27.40% | 22.45% | -24.42% | 全期仍为正，但不满足20%回撤目标 |

正式成本门要求30bp开发期和选择期分别为正、30bp全期至少保留20bp收益的60%、50bp全期仍为正。`simple_v2`的30bp保留比例为74.17%，全部登记条件通过。

旧候选曾在30bp下突然转负，原因不是额外10bp费用本身，而是更低净值更早触发组合回撤阈值，随后仓位和持仓路径分叉。`simple_v2`用固定政策成本参考净值驱动回撤状态，避免成本假设暗中改变策略；实际净值仍按10/20/30/50bp分别扣费，所以压力结果没有少计成本。

## 大盘风险评估

系统同时输出0-100的“板块广度健康分”，输入为行业与概念板块的60日趋势、20/60日上涨宽度和20日波动率历史分位。它用于解释当前风险环境，不是未来收益率预测。

绝对板块仓位由已确认的市场状态与组合回撤上限共同决定：

- `RISK_ON`：基础仓位100%；
- `NEUTRAL`：基础仓位70%；
- `DEFENSIVE`：基础仓位30%；
- `CASH`：基础仓位0%；
- 最终仓位取市场基础仓位和组合回撤上限的较低值。

截至2026年8月28日，健康分为47.0，原始和确认状态均为`DEFENSIVE`，目标为30%板块、70%低风险资产。模型目标板块为：

| 板块代码 | 板块名称 | 目标权重 |
|---|---|---:|
| `884080.TI` | 能源及重型设备 | 10% |
| `885410.TI` | 固废处理 | 10% |
| `885835.TI` | 参股银行 | 10% |
| `511880.SH` | 货币ETF | 70% |

这是8月28日收盘形成、对应8月31日开盘复核的历史计划。由于ETF执行层被阻止，不能在之后补单。

## LightGBM如何训练

正式模型使用冻结的18项人工特征和固定超参数。每个季度开始前，只使用当时已经完成标签兑现的历史样本重新训练；评分窗口向前滚动，训练窗口持续扩展。2024-2025只用于比较年度与季度重训等方案，最终选择季度扩展窗口。

模型学习的是跨多个市场阶段的板块相对排序，不是只拟合最近几周的局部行情。市场绝对强弱不由LightGBM直接承担，而由独立的市场状态与组合回撤层控制。因此当前闭环分成两层：

1. LightGBM回答“在当前可用板块中，相对更值得持有哪些”；
2. 风险层回答“现在总共应该承担多少板块风险”。

这套分工仍有局限：跨周期训练提高稳定性，但对突发结构变化反应较慢；风险层以价格和广度为主，也可能在快速下跌初期确认偏晚。

## 独立市场信息复核

研究分别检查了宽基指数、全A等权及市值加权宽度、申万一级中期趋势、个股资金流、估值、换手和财务初始公告扩散。结论如下：

- 全A20日净流入与未来20日收益存在方向性信息，但加入仓位规则后未同时通过收益、回撤、换手和30bp门；
- 季度扩展Ridge市场模型在2018-2023的滚动Spearman为-0.205，方向失败，未进入策略回放；
- 初始财报扩散的月末60日Spearman仅0.033，高分组收益反而比低分组少约3.6个百分点；
- 固定5日或10日调仓不是稳定低频方案，10日规则在不同起始锚点下开发期收益从-1.5%到+106.4%，锚点依赖过强。

这些信息均未进入`simple_v2`。当前正式提升来自持仓缓冲和成本独立的风险参考账本，不是新增预测变量或事后反转信号。

## 旧高收益原型为什么不能直接恢复

旧项目中的年度扩展LightGBM、每日Top5、零成本原型已经精确复现。但旧协议把收盘形成的信号与下一行收盘收益相连，包含开盘前无法成交的隔夜变化；训练边界也没有保证截止日前最后一批标签已经兑现，排名宇宙和缺失收益处理也与当前执行协议不同。

在相同年度扩展训练、每日Top5、零成本条件下，旧收盘口径与修正后开盘口径的累计收益分别为：

| 期间 | 旧收盘口径 | 当前开盘口径 |
|---|---:|---:|
| 2018-2023开发 | 268.48% | 139.56% |
| 2024-2025选择 | 173.84% | 92.22% |
| 2026截至5月29日 | 20.76% | 13.44% |

差异来自多项协议修正的联合影响，不能当作单一因素贡献，但足以说明旧高收益的一部分不可直接交易。当前项目不会为了恢复旧数字撤销次日开盘执行、标签兑现边界或缺失行情约束。

## ETF执行层

板块指数策略与真实ETF之间仍有明显落地缺口。系统按月用历史相关性、β、上市时间和流动性做严格映射，再以真实ETF复权开盘价回放目标组合。

`simple_v2`目标翻译后的20bp全期参考收益约17.51%、最大回撤约-0.49%，但历史平均映射覆盖只有0.73%，观察期覆盖为0。绝大多数板块权重被透明回退到`511880.SH`，因此表面的低回撤和正收益主要来自货币ETF，不能解释为板块策略可以交易。

当前三个目标板块的严格ETF映射覆盖均为0，`ETF_EXECUTION_READINESS.json`状态为`blocked`，`LATEST_ACTIONS.csv`保持为空。系统不会生成伪映射，也不会把未映射板块权重伪装成可执行订单。

## 前向证据与使用边界

v8曾记录2026年8月11日至28日共14个当时真正未见的交易日，但它属于旧策略。v9-v13已经归档。`simple_v2`从v14重新冻结，冻结日为2026年8月28日；截至本报告，v14只有冻结基线，还没有新样本。

因此当前结论应这样使用：

- 可以把`simple_v2`作为板块选择、市场风险和目标仓位的研究参考；
- 可以用结构化账本持续记录未来未见数据；
- 不能把2018-2025历史门通过解释为独立样本外成功；
- 不能在ETF映射安全门未通过时直接下单；
- 不能根据已经看到的2026结果继续修改规则后仍声称2026是验证集。

## 日常运行与核对

先运行`python -m ga_factor_mining.sector --check`完成自检，再运行`python -m ga_factor_mining.sector`。日常优先核对`LATEST_STATUS.csv`、`LATEST_MARKET_RISK.json`、`LATEST_TARGET_PORTFOLIO.csv`、`ETF_EXECUTION_READINESS.json`、`ACCEPTANCE_GATE.json`和前向`STATUS.json`。

**最终判断：** `simple_v2`已经达到当前历史研究门：相对`simple_v1`提高了多年平均收益、降低了回撤和换手，并通过30bp及50bp成本条件；同时保留清晰的大盘风险仓位输出。它是目前最合适的默认研究闭环。但真实ETF覆盖和新的前向样本仍然不足，所以定位仍是“实盘参考”，不是自动交易系统或已被独立样本证明的产品。
